# Recursos oficiales de CLIMON

No se ha creado un logotipo ni isotipo. La cabecera muestra temporalmente el nombre en texto.

Agregar los recursos aprobados como `logo-climon.svg`, `logo-climon-white.svg` e `isotipo-climon.svg` y actualizar `src/config/site.ts`.
